# Project Instructions — SQL Judge for Unilever Database

## Versioning

- Version is tracked in the `VERSION` file (semver format, e.g. `1.2.3`).
- The version badge is displayed at the bottom-right corner of the web UI.
- **ANY change** to any project file (code, config, data, docs, assets) must bump the version in `VERSION` according to semantic versioning (`MAJOR.MINOR.PATCH`).
- **Never aggregate changes from different builds** — each change session gets its own version bump. If two edits are made, there must be two separate commits with two separate version bumps. Do not batch multiple changes under one version number.
